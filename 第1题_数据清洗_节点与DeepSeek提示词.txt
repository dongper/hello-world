第 1 题｜数据清洗工作流｜老师式节点提示词
版本：2026-11-15 修订

怎么用
------
1. 每题新开一个 DeepSeek 网页对话，先发完整题目，包含字段、规则、报告模板、提交要求，再附实际文件表头和少量必要样例。规则表很短时应给完整规则；表头看不出含义时补代表性数据。完整数据上传 Dify 运行，不用逐行粘到网页里。
2. 对 DeepSeek 说：“我用 Dify 1.14.2，从零搭建。先读题，不要一次生成整个工作流。我会逐节点给你输入、处理、输出要求；你每次只写当前节点完整代码。”
3. 下面的代码节点，每次复制【复制给 DeepSeek】至【提示词结束】整个区块。前面题目和上一节点的代码保留在同一对话。
4. 文件、提取器、条件分支、工具、模板、输出节点按本文直接配置。第二题的 SYSTEM／USER 是粘到 Dify 模型节点中，不是粘进 Python。
5. 左边输入变量名必须与 main 参数一致；右边用变量选择器选来源；输出名、类型必须与 return 一致。String 只是类型，CSV 和 JSON 内容不能混用。
6. 每完成一个代码节点，临时连接输出，绑定该节点报告检查。正式提交前按末尾最终输出配置，并跑完整流程。
7. 所有“当前数据校验值”仅适用这批练习数据。正式考试变动时，以现场完整题目及发放数据为准，不强行凑数字。未做端到端执行的提示词不等于已验证的考试答案。

本题画布
--------
01 上传 → 02 五个提取器 → 03 表结构统一 → 04 时间统一 → 05 ID 修复 → 06 缺失还原与统计 → 07 Markdown 转换与总报告 → 08 五个文件工具 → 09 输出

本版采用老师提供的 06 节点输入输出。三张主表从 05 直接绑定到 07，不在 06 重复输出。中间表用 CSV String，最终表才转 Markdown。原版任务四的代码不能只改几个变量就接入新版，需按 06、07 分别生成代码。
